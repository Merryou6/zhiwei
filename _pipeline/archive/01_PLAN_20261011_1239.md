七、风险与回滚
-------------------------------------------------
R1【高·规模】本需求 ≈ 重写整个前端表现层（规范 + 组件库 + 外壳 + 17 页），单轮流水线
   （implementer+reviewer）无法一次完成；缓解：批次严格线性、每批独立提交可独立回滚、
   任意批次后停下全站仍可用（未迁移页面以过渡态运行：token 已换值 + 旧结构外壳或新外壳
   简化形态）；建议总控按批次拆多轮执行，优先级 = P0→P5（规范+组件库+外壳）为最小
   可交付链，P6/P7（首迁页+图谱）为质量定型链，其后按批次铺开。
R2【高·门禁中间红】P2 改期望后 P3 落地前四测试文件为红（预期中间态）；缓解：P2/P3 两批
   紧邻执行、各自独立提交（门禁改动独立成提交），全绿判据在 P3 末尾；reviewer 按「P3 末
   全绿」验收而非逐批快照。
R3【高·外壳切换】P5 是信息架构级重构（顶栏退役、四层骨架、面板阈值 1280/720→1180/900）；
   回滚：P5 单批 revert 即回旧外壳（P3/P4 的 token 与组件改造不依赖新外壳）；
   缓解：chatPanel/mobileNav store 零改动 + chatPanel/mobileNav/dialogStore 测试全绿 +
   3.2 冻结区命令逐批复核 + 走查三档截图。
R4【高·ECharts 还原度】键盘漫游/描边入场/节点焦点环在 ECharts canvas 上无原生对应；
   缓解：D8 预排序（能落定项先做、评估项尽力），做不到的在批次 2 变更说明如实记录与
   原型差距（红线：记录不静默砍）；回滚：P7 单批 revert。
R5【中·面板与标题栏/引线打架】面板打开挤压图纸 vs LeaderLayer 引线锚点失效、TitleBlock
   与面板幕布层级；缓解：P5 一并处置（面板开时引线停用、标题栏层级高于幕布——需求
   文档 §5 口径）；走查 1180 档开面板截图专项核对。
R6【中·中文字体体积】Noto Sans SC 全量数 MB；缓解：走 @fontsource 分片（unicode-range
   按需加载，与 Google Fonts 同源分片方案）；P3 末用 vite build 产物体积实测留痕，
   超预期（主包 +1MB 以上）则只保留批注场景子集并在变更说明留痕。
R7【中·60s 命令限制】缓解：6.1/6.2 全部命令已分批分条；走查按单宽度×单主题拆条。
R8【中·文案与 phrases 冲突】原型文案不采纳（D5），但页面重排可能移动文案位置；
   缓解：phrases.test.ts 不动，改版后全绿即文案未漂移；新增 .tok 批注文案走组件库常量。
R9【低·未迁移页面过渡态观感】token 换值后未迁移页面自动穿新配色（拍板共存策略）；
   中间态观感混杂是接受的过渡，不是缺陷；回滚整链：P3 revert 即回旧配色。
R10【低·规范文档与实现漂移】P0 规范先行、实现可能发现规范笔误；缓解：改动回写规范文档
   同批提交（规范是活文档，但只增与留痕修订，不静默改）。
回滚总原则：每批独立 commit、互相不混提（AGENT §7）；页面批单页单提交；任何一批出问题
   单批 revert 不影响其余；回滚页面批需先于回滚 P5/P4/P3（依赖链反向）；_pipeline/archive/
   与 _pipeline/screenshots/ 产物只增不删。
