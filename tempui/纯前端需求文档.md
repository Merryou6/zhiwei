## 1. 产品概述与目标用户

### 1.1 产品定位

**知微**：基于知识图谱归因的一对一 AI 学习伴侣，聚焦中学数学。

核心体验是一条五步闭环：

```
采集证据 → 诊断掌握度 → 定位根因 → 生成处方 → 新题验证
```

- **采集证据**：起点自报（30 秒问卷）、自适应测评、试卷错题确认、对话辅导，全部静默采集，不打扰
- **诊断掌握度**：每个知识点一个 0–1 掌握度，映射为四档「状态带」着色，全站统一
- **定位根因**：错题不止于「哪题错了」，沿知识图谱的先修链向上回溯「真正卡住的是哪一环」
- **生成处方**：学长式对话与练习，一次只给一小步提示，不抛答案
- **新题验证**：零重叠复测题，用 ΔAccuracy（正确率变化）验证干预效果

### 1.2 目标用户

| 用户 | 场景 | 前端诉求 |
| --- | --- | --- |
| **学生**（主用户） | 初中/高中数学学习者；用自己的「学习空间」走完五步闭环 | 低压力、无评判、随时可进出的学习界面；**测评过程绝不即时反馈对错**（分数攒着一起看），练习过程则逐步明确批改——两种通路两种目的，是本产品最重要的交互纪律之一 |
| **教师** | 用邀请码与学生绑定，查看学情摘要、下发知识点推荐 | 只读工作台：学生卡片墙、单个学生画像、推荐管理；**明示看不到学生与学长的对话内容**（未成年人数据保护是产品卖点） |
| **未登录访客** | 从落地页了解产品 | 四章滚动叙事门户页，一键进入登录/演示 |

### 1.3 体验主张（重构时应保留的产品性格）

1. **一屏一件事**：每页只有一个主任务，第一屏就让用户开始
2. **学长人设**：文案像耐心的学长，绝不像评判者。全站有评判词黑名单（「错误」「很差」「笨」等禁用）
   - 知识点薄弱 → 不说「你掌握很差」，说「这一环还有点晃，我们再稳一下」
   - 答错了 → 不说「回答错误」，说「这个坑很常见，我们看看它是怎么来的」
   - 归因成功 → 不说「检测到知识缺陷」，说「找到啦——真正卡住你的是这里」
3. **采集永不弹窗**：所有证据采集走非阻断气泡/toast；全局唯一的模态框只用于用户主动操作的确认（删除、切换、退出）
4. **低压力退出**：连续几轮没进展不硬耗——对话页有「退出通道」，明说「不丢人」
5. **空态不伪造数据**：没有就是没有，骨架屏用纯灰块不放假数据
6. **数学是主角**：等宽数字、数学符号快捷面板、分步书写区，处处为「写过程」服务

### 1.4 信息架构（纯前端层）

**URL 形态**：hash 路由（如 `#/login`）。是否沿用待与重构方确认（见 §6）。

**路由守卫规则**（前端状态：登录令牌 + 活跃空间，均存 localStorage）：

| 情形 | 重定向到 |
| --- | --- |
| 未登录访问任何受保护页 | `#/login` |
| 已登录访问登录页 | `#/spaces`（学生）/ `#/t`（教师） |
| 已登录但无活跃空间（`#/spaces`、`#/self-report` 豁免） | `#/spaces` |
| 未知路径 | 已登录→`#/spaces`，未登录→`#/login` |
| 教师路由 `/t/*` | 仅要求登录，不要求活跃空间 |

**本机会话小状态**（localStorage / sessionStorage，均为进度标记，丢失无业务损害）：

| 键 | 用途 |
| --- | --- |
| `zhiwei_token` / `zhiwei_user_id` / `zhiwei_role`（student/teacher） | 会话 |
| `zhiwei_active_space` | 当前空间 |
| `zhiwei_theme`（默认 dark） | 主题偏好 |
| `zhiwei_sr_done_<space_id>` | 该空间已完成起点自报 |
| `zhiwei_recognition_id`（session） | 试卷识别中刷新回显 |
| `zhiwei_paper_wrong_<space_id>`（session） | 试卷错题缓存，归因页「一键带出」 |

**页面切换转场**：180ms 渐入（随路径切换重放）；每个页面独立错误边界，报错只废当前页（保留顶栏可逃离），提供「重新打开这一页 / 回到学习空间」两个出口。

## 3. 页面详细需求

### 3.0 全局外壳（学生端 Layout）

除登录页、门户页、教师端外，所有页面共用同一外壳。

**布局**：顶栏（sticky，实底，下边框）+ 主内容区（最大宽 1152px 居中，页边距桌面 24px / <720px 时 16px）+ 右侧常驻对话面板 + 移动端汉堡抽屉 + 右上角 toast 栈。外壳最小高 = 视口高（`min-h-dvh`，防移动端地址栏抖动）。

**顶栏内容**（左→右）：

| 元素 | 说明 |
| --- | --- |
| 品牌位 | 「知微」logo + 字标；未登录显示「学习伴侣」 |
| 主导航 6 项 | 测评 / 对话辅导 / 专项练习 / 知识图谱 / 学习报告 / 我的；激活态 = 主题色浅底 + 2px 主色下划线条；**「对话辅导」是开合按钮**（aria-pressed），点击切换右侧面板而非跳转 |
| 主题切换 | 36px 方钮，太阳/月亮图标，aria-pressed |
| 空间胶囊 | 立方体图标 + 「空间·xxx」+ 下拉箭头；点开弹层：空间列表、原地展开的新建表单（紧凑态）、「管理空间」入口；外点/Esc 关闭且焦点归还 |

**右侧常驻对话面板**（对话辅导的载体，跨路由保持状态）：

- 宽 400px；**≥1280px**：常驻挤压式——顶栏与正文同步右让（同一 CSS 变量驱动，左基线恒对齐不跳动）；**<1280px**：覆盖式抽屉 + 背景幕（点幕或 Esc 关闭），正文不动
- 面板内容与全屏对话页（`/chat`）**同一套实现**；「全屏打开 ↔ 收进侧栏」互逆切换，上下文不丢
- 层级刻度：导航 40 / 覆盖层 50 / toast 60

**移动端汉堡抽屉**（<720px 顶栏只留 logo + 汉堡键）：

- 全高右滑抽屉（宽 min(320px, 85vw)），承载：6 导航项、主题切换、当前空间切换、新建空间、管理空间
- 无障碍闭环：焦点陷阱（Tab 不逃出）、Esc 关闭、关闭后焦点归还汉堡键、打开期间正文 `aria-hidden`、路由变化或视口拉宽到 ≥720 自动关闭、与对话面板双向互斥
- 已知边界（现有项目接受现状）：**恰好 720px 宽**处顶栏高度由 68px 变 88px（断点含/不含端点语义差异），单行不换行、无溢出

**Toast**：右上角堆叠，非阻断，自动 6 秒消隐，每条带「知道了」关闭钮；三档语义：info（主题色圆点）/ warn（暖橙圆点）/ error（错误色边框+浅底）；无 success 档——成功提示也走 info；容器 `aria-live=polite`。

### 3.1 `/login` 登录/注册

**布局**：不套外壳，全屏单屏居中。自上而下：氛围背景（单色相径向光 + 漂移光斑）→ 粒子 logo（尺寸随视口三向夹取，防矮屏挤压）→ 品牌字（宽字距）→ 一句话定位 → 无边框表单（最大宽 360px，placeholder 承担标签，视觉标签仅读屏可见）→ 演示入口。版式纪律：整屏元素压至 8 个。

**组件**：

| 组件 | 状态与交互 |
| --- | --- |
| 身份二选一组（学生/老师） | 常驻分段控件（aria-pressed）；注册时决定账号角色，登录时是身份期望（不符则温和纠正：toast「这个账号是老师身份——已按老师端进入」） |
| 账号输入 | placeholder「手机号或邮箱」 |
| 密码输入 | 注册态 placeholder「设个密码，至少 6 位」；autocomplete 按注册/登录区分 |
| 昵称输入（仅注册） | 可选，「怎么称呼你（可留空）」 |
| 主按钮 | 44px 触控下限；loading 态文案自切「正在处理…」；文案随模式：「进去看看」/「注册并开始」 |
| 通道切换 | 文字链「第一次来？30 秒注册一个」/「已经有账号了？去登录」 |
| 演示入口 | 「用演示账号看看学生端/老师端」+ 等宽明文演示账密；逻辑：先登录，未建过则自动注册 |

**校验**（行内错误 + toast 双通道，输入即清除）：账号空 →「先填手机号或邮箱，我才能记住你」；密码空→「密码还没填」；<6 位→「密码至少 6 位」。

**流程分叉**：注册成功 → 自动建好默认空间（toast「已为你建好「初中数学」学习空间」）→ **必经 `/start`**；登录成功 → `/spaces`；教师角色 → `/t`。

**数据展示**：纯表单页，无列表、无骨架。

**响应式**：标识尺寸 `min(264px, 56vw, 27vh)` 防矮屏；表单恒 360px。

### 3.2 `/start` 冷启动分叉（注册后一次性落地页）

**布局**：单列窄容器。页头（「两种方式认识你」）→ 两张路径大卡（错峰渐入，hover 上浮）→ 次级入口行。

**组件与流程**（纯静态导航页，无状态机、无加载态）：

| 选项 | 卡片内容 | 去向 |
| --- | --- | --- |
| A（推荐） | 「拍一张最近的试卷」+ 徽标「推荐 · 零负担」+「月考卷/答题卡/平时作业都行」+「我按卷面错题建你的知识地图，一分钟就好」 | `/paper` |
| B | 「先做几道摸底题」+「大约 10 分钟」+「边做我边记：哪里稳、哪里晃，地图随着作答一格格亮起来」 | `/assessment` |
| 次选 1 | ghost 按钮「都先不了，花 30 秒自报个大概」 | `/self-report` |
| 次选 2 | 文字链「先去空白的技能树看看」 | `/graph` |

### 3.3 `/self-report` 起点自报

**布局**：单列窄容器，两态切换。

**作答态**：页头（「先说说你大概在哪一档」+「这不是考试…30 秒够用」）→ 进度卡（左「已选 n / 总数 个章节」等宽数字，右「按 3 档先填上」次按钮）→ 章节卡列表 → 底部全宽主按钮「记下来，开始测评」。

**章节卡**：卡头 = 章节名 + 「N 个知识点」；卡内 5 档单选按钮组：

| 档位 | 文案 |
| --- | --- |
| 1 | 几乎没学过 |
| 2 | 听过，不熟 |
| 3 | 会一点，会晃 |
| 4 | 比较稳 |
| 5 | 很熟 |

默认全不选；「按 3 档先填上」= 一键全部置 3（防全零掌握度导致测评立即收敛的产品决策）。

**流程**：逐章选档（或一键 3 档）→ 提交 → 成功切换到**成功态**：「起点记下了」+ 大字「已更新 N 个知识点的起点」+ 双按钮（「开始测评」主 /「先看看我的地图」次）。提交成功同时写本机标记（空间页按钮文案切换用）。校验：0 章节选中 → toast「至少选一个章节，或者点『按 3 档先填上』」；无活跃空间 → 统一拦截。

**纪律**：全程不出现任何对错/评价措辞；数据本地即得，无加载态。

**响应式**：档位按钮 flex 换行。

### 3.4 `/spaces` 学习空间

**布局**：中等宽容器。页头 → 四态互斥分支 → 尾部新建面板。

**四态**：教师提示卡（「老师账号不用建学习空间」+ 回老师端）/ 加载骨架「正在取你的空间…」/ 空态 / 空间卡列表。

**空间卡**：

- 标题行：空间名 + 「默认空间」徽标（默认空间）+「当前使用」徽标（激活卡，青绿色）；副行：学段学科名 ·「创建于 yyyy-mm-dd hh:mm」
- 激活卡按钮组：并列双入口「进入学习」（主，→ 测评）+「自报 / 拍卷建图」（次，→ `/start`）
- 非激活卡：「切到这个空间」
- 激活卡加旋转渐变描边强调

**新建空间表单**（本页完整态与顶栏弹层紧凑态同一实现）：

- 学科单选：初中数学 / 高中数学
- 空间名：可选，上限 **30 字**（前后端同源），placeholder「不填就用学科名」
- **重名自动后缀**：本地重名时自动建议「名 2」「名 3」…且恒 ≤30 字
- 服务端重名冲突（409）→ 全局唯一模态框：「已有同名空间…要切到已有的那个吗？」默认按钮「切换过去」

**空态**：EmptyState「还没有学习空间」+ 主按钮「新建学习空间」（点开才展开表单——防双主按钮抢注意力）。

**数据字段**：space_id、name、knowledge_source（学段学科标识）、is_default、created_at。

**响应式**：卡内标题行与按钮组换行堆叠。

### 3.5 `/assessment` 测评（自适应出题）

**布局**：三屏状态机 `select → question → done`。

**select 屏**：页头「选一种测评」+ 3 张模式卡（错峰渐入，「点了即开始」无二段确认）：

| 模式卡 | 文案 | 备注 |
| --- | --- | --- |
| 诊断测评 | 「挑几道练过的题，专门找你现在卡在哪儿」 | `?kp=` 带入时附定位提示「已按你在技能树点的知识点定位到「某章」」 |
| 基线测量 | 「先做 3 道题，记下你现在的高度…」 | |
| 复测测量 | 「补完之后，做几道没见过的新题…」 | `?mode=retest` 仅高亮预选「已为你选好这个模式，点卡片就开始」，**不自动开跑** |

**question 屏**（自上而下）：进行中状态条（左=模式名，右=「剩 N 题」）→ 进度条（「已答 n / m」，**只反映数量不含对错**）→ 题卡 → 操作行（「下一题」主 +「这道先跳过」）→ 中途路标卡（答满 ≥2 题出现：「已经记了 N 题（可随时离开，进度留着）」+ 去图谱/报告）→ 底部纪律文案「我不会当场告诉你对错——分数攒着，等这一轮完了我们一起看整体。跳过也没关系」。

**单题循环**：作答（空答案拦截「写点东西我再往下走（写一步也行）」）→ 提交 → 换下一题；跳过 = 记入已答集合并从后续出题中排除。

**核心纪律**：**全过程绝不展示对错**（即使响应里有判定也一律不渲染）；题面只渲染题干与选项，答案与解析永不出现在前端。

**done 屏**：按模式分流（NextStepCard 模式）：

| 结束情形 | 主按钮 | 次按钮 |
| --- | --- | --- |
| 诊断测评 | 「看看我的地图」→ /graph | 「打开学习报告」→ /report |
| 冷启动立即收敛（0 题） | 「去花 30 秒自报」→ /self-report | — |
| 基线测量 | 「去对话页补一补」→ /chat | — |
| 复测测量 | 「去报告看变化」→ /report | 「换一种测评」（回 select） |

**响应式**：操作行换行；无特殊断点。

### 3.6 `/paper` 试卷上传（三段流程）

**布局**：三态 `pick → confirm → confirmed`。

**① pick 选文件**：页头「传一份卷子」+ 演示态说明（「从预置文件里挑（可多选，最多 5 页拼一份整卷）。识别结果只是草稿，对错由你最后确认」）→ 计数行「已选 n/5 页」+「清空」→ 文件卡列表 → 全宽主按钮「开始识别（N 页整卷）」。文件卡：名称 + 类型大写 + 人性化大小 + 文件 ID（长串强制断行）；点选切换，默认选中第一个；上限 5 页。**刷新回显**：识别中刷新，凭 session 里的识别 ID 直接恢复到确认屏。

**② confirm 逐题确认**（识别完成的判定草稿，对错由用户敲定）：识别状态行「识别完成，等你逐题确认」+ 计数「已标 n/m」→ 逐题行列表 → 底部操作行。每行：

- 「第 N 题」+ 题干摘录 +「你的作答：…」（空显示「（识别为空）」）
- 判定区：识别不确定 → 徽标「这题我没看清，麻烦你标一下」；否则「参考：疑似对 / 疑似错」
- **知识点控件（减负设计）**：识别有猜测 → 默认收成徽标「识别猜的 · 某知识点 ▾」（不碰即视为确认），点开才见按章节分组的下拉（选完自动收起）；识别没猜 → 直接给分组下拉 + 禁用占位「请选知识点」（不装作有默认）
- 对错双按钮「这题对了 / 这题错了」（可撤销重选，**所有行无默认值**）

底部：主按钮「确认，更新掌握度」（未标完禁用）+ 快捷键「按参考标好没标的题」（一键采纳参考判定，不确定项仍须手标，toast「已按参考标好 N 题，过一眼再确认」）+ 剩余提示三态（「还有 N 题没标」/「还有 N 题没选知识点」/「标完了，过一眼再确认」）。

**③ confirmed 完成**：摘要卡「新增了 N 条证据，更新了 M 个知识点」；冷启动时追加「你的初始图谱已生成：覆盖 X 个知识点，Y 个待巩固」；掌握度变化逐行「知识点：87% → 92%」等宽数字；错题自动缓存到本机（供归因页一键带出，页脚明示）。按钮组：冷启动主按钮「看看你的技能树」（→ `/graph?bootstrapped=1`）；否则主按钮「挑错题看看根源」（→ `/attribution`）；次按钮「再传一份」。

### 3.7 `/practice` 专项练习（逐步批改）

**布局**：三段 `select → ladder → summary`。

**select 屏**：页头「专项练习」→ 章节 Selector（`?kp=` 预选）→「开始专项阶梯」→ 本章进度行（练过 N 题 · 平均通过率 x%；未练过则「这一章还没练过——第一组题会从最容易的开始」；取数失败明示「进度暂时取不到」）→ 概念卡折叠面板（默认折叠「先看看『某章』的知识体系（N 张概念卡）」；展开骨架；**失败诚实降级**「概念卡没取到，稍后再试」+ 重试按钮，不伪装空集）。概念卡内容：定义 / 关键点 / 易错点（「易错：」前缀）/ 折叠典型例（题干 + 有序步骤 +「触类旁通」关联知识点名）。

**ladder 屏**（逐题）：

- 头部：「分步写，我逐步批」+ 计数「某章 · 第 n/m 题」+ 阶梯难度（0–5 难度圆点）+ 阶梯进度点条
- **分步编辑区（上限 8 步）**：每步 = 「第 n 步」编号 + 上移/下移/删除 + 文本域（首步 placeholder「第一步怎么下手？」）；删除非空步骤弹确认框「删除第 n 步？——这一步已经写了内容，删除后找不回来」
- **提示链（逐级解锁，每题重置）**：L1「给个方向」→ 展示解题方向；L2「再给点思路」→ 展示提示；第三级文案引导「把过程写出来提交，逐步批改带你走」（知识点级提示不泄题）
- **提交「提交，逐步批改」** → 空步拦截「把每一步都写点什么（不会的那步写『不会』也行）」
- **逐步批改结果**：每步一枚判定徽标（错峰渐入）：

| 判定 | 徽标文案 |
| --- | --- |
| pass | ✓ 这步对了 |
| slip | ⚠ 运算失误 |
| concept_gap | ✗ 思路断点 |
| unclear | ？ 这步我没看懂，再写清楚点？ |

  每步附反馈文本与「下一步往哪想：…」；**断点步**加警示描边 + 闪烁动画 + 自动滚动到位；判后**仅断点步可继续编辑**（其余锁定），断点步可「按提示改这一步，重新批改」——重批不重复计入战报（以首次提交计；1 小时内同题重复提交明示「这道题刚才批过」）
- **总评卡**：「终点抵达了正确答案。」/「这次没能走到正确答案，但过程都记下了」+「断点在第 N 步」/「每一步都过了」+ 通过率数字爬升动画（=1 显示「全部」）
- 操作行：「下一题」/「做完这组，看战报」；「换一章」有未提交内容时弹确认「这一题还没提交——换一章会丢掉已写的过程」

**summary 战报屏**：全对时成功对勾描边动画 → 战报卡大数字「n/m 题 走到正确答案」（超大字号）+ 平均通过率爬升 + 本章累计（练过 N 题 · 提交 M 次 · 平均通过率 x%）→ 按钮组：「再来一组（自动避开刚练过的）」/「补完做 2 道复测，验证效果」（→ `/assessment?mode=retest`）/「换一章」/「看看技能树」。

**选择题特例**：所选选项文本作为单步提交，同样走逐步批改。

### 3.8 `/chat` 对话辅导（全屏版；右侧面板同实现）

**布局**：宽容器双栏。宽屏：左消息列（最大 672px）+ 右「思考与工具链」侧栏（约 304px）；<720px 上下堆叠。页头「跟学长聊两句」+「卡在哪一步就说哪一步…我不会直接给你答案」+ 主题徽标（「本地规则」/「远程大模型」+ 模型名 +「由服务端配置，不可自定义」）。

**消息流**（三种气泡）：学生消息右对齐主题色浅底；学长消息左对齐、支持轻量富文本（代码/公式块）；通知类居中。徽标体系：「方向提示」「换条路走走」；低置信回复带注脚「我不太确定说的是哪个知识点，可以再描述一下吗」。图片附件：题图缩略图（刷新后兜底文案「这条消息带过一张题图（图片不保存）」）。流式输出期间自动贴底滚动（尊重减动效偏好）。空态「还没有聊天记录」。

**输入区**：多行文本框（44px 触控下限）+「传图读题」+「发送」。选图本地压缩（≤1280px、质量 0.72）后随下一条消息发送；预览卡「题图备好了，随下一条消息一起发」+「重新选一张」。流式中发送禁用（文案「正在回…」）。

**思考与工具链侧栏**（透明化设计，重构时值得保留的产品特色）：

- 折叠条「思考与工具链」+「进行中」呼吸点 /「N 步」；流式期间自动展开，用户手动收起后不再自动弹开
- **思考流**：打字机逐字（约 24ms/2 字符，减动效直出）；空态「正在整理思路…」；完成态「这一轮没有推理摘要。」
- **工具时间线**：四阶段进度（analyze → retrieve → judge → generate，「阶段 n/4」）；每步卡片：状态图标（进行中转圈/完成 ✓/失败）、中文名、真实耗时 ms、入参与产出键值对（值截断展示）。工具名七项闭集：加载图谱 → 模型调用 → 知识点匹配 → 查重 → 采纳证据 → 状态更新 → 退出通道
- 空态「还没有调用工具。」

**回复流程与降级链**（不白屏纪律）：发送 → 学生气泡入列 → 「正在想…」占位 → 增量流式追加 → 元信息落定 → 完成。降级：① 响应不是事件流 → 整段渲染 + toast「刚才网络卡了一下，已转为普通回复」（过程信息按序补放）；② 流中断 → 降级重发一次；③ 仍失败 → 错误气泡。

**退出通道**（低压力设计）：连续多轮无进展时，页头出现显著提示条：「我们先往回看一眼『某知识点』，那里可能是关键」+「连续几轮都没往前走…不丢人」+ 按钮「去图谱看看这一环」（→ `/graph?path=kp_id`）。

**页头实时元信息**：「这轮在聊：某知识点（置信 N%）」（置信 < 60% 时触发澄清话术）。

### 3.9 `/attribution` 归因结果（四步向导）

**布局**：向导态窄容器、结果态中容器。步骤眉标**刻意不做进度条**：「第 1 步 · 挑一道错题」→「第 2 步 · 先复述一遍」→「第 3 步 · 我再确认一下」→「第 4 步 · 看看属于哪一类」。

**向导流程**：

1. **挑错题**（双来源）：a. 试卷错题列表（「这个空间里记下了 N 道错题」，来自本机缓存）；b. 手填（题干 + 作答 + 知识点下拉「章节 / 名称」）
2. **复述确认卡**：把学生的作答复述一遍（纪律：先复述再判定）
3. **错误分类**：判定不确定 → 就地追问「我拿不准就不硬猜」+「再判一次」（不自动往下走）；确定 → 五类错误类型枚举卡常显、命中高亮（前置知识缺口 / 概念混淆 / 方法缺失 / 操作失误 / 审题失误），附证据与「把握 N%」
4. **分叉**：属于操作/审题失误（无需归因）→ 明示「这类小失误不用归因」且**不提供深挖按钮**，仅「再练几道」；其余 → 「看看真正的根源」→ 分析 → 跳结果态

**结果态七区**（自上而下）：

1. **Hero**（非卡片，2px 主色标线定调）：徽标组（错误类型 / 已验证 / 已记录你的反驳）+「找到啦——真正卡住你的是这里」+ 根因知识点大字 +「归因编号 x · 回溯 N 层」
2. 「为什么是这里」解释区
3. **纵向路径链**：连接线串起回溯路径，根因节点带光环「根因就在这里」
4. 「其它可能」：次选嫌疑前三，附贡献度条
5. **验证区**：一道验证题（题卡 +「提交这一步」）；通过 →「验证通过——这一环确实是我们该补的地方」；尝试耗尽 →「暂时没找到更深的根源…」
6. **处方**（仅验证通过后成卡）：学习策略 + 讲解大纲 + 题目序列（难度徽标 + 题干）+「去图谱看学习路径」
7. **页脚反驳通道**：可选理由 +「提交反驳，换一道验证题」；「换一道错题重新归因」

**回显**：`?attribution_id=` 进入（从图谱/报告点来）先骨架「正在取这次归因的结果…」防闪屏。

### 3.10 `/graph` 知识图谱（技能树，兼学习路径页）

**布局**：宽容器。页头「你的技能树」→（`?bootstrapped=1` 时）冷启动横幅「初始图谱已生成：覆盖 N 个知识点，M 个待巩固」→ 证据计数器行 → 画布图谱 → 文字版清单（折叠 details，无障碍兜底）→ 页脚统计。图表库独立懒加载（首屏不带它），加载期骨架。

**证据计数器行**（数字动效）：「这张图谱记录了你 N 条学习证据」+「本周点亮 +N」（数字随节点点亮爬升 + 落地弹跳）+「已覆盖 x/y」+ 章节徽章「某章 ✓ 通关」。

**图谱本体**：

- **确定性分层布局**（非力导向）：列 = 最长先修链深度，同输入同输出——刷新不跳
- 交互：画布缩放 + 平移；**节点不可拖**；节点点击 → 详情卡（章节 · 难度 · 掌握度 + 带色 · 证据 N 条 · 先修链）+ 行动按钮组：「去攻克」（→ `/assessment?kp=`）、「分步练一道」（→ `/practice?kp=`）、薄弱点额外给「做 2 道复测」（→ `/assessment?mode=retest`）；打开详情时画布降饱和聚焦
- **节点六态**：四档掌握度实色 + 未接触空心 + 未解锁灰心；低置信节点虚线边框 +「？从旧卷估的——做 2 道复测会更准」
- **?path= 学习路径高亮**：路径节点放大 + 主色描边，非路径节点降透明；路径边主色加粗；两端均已掌握的「打通」边亮色（成就感设计）
- **点亮动画**：逐节点错峰点火（全图约 1.7 秒），减动效瞬时完成；主题切换重绘不重播
- 图例：四色状态带圆点图例（可选计数），纯展示不可点

**空态**：「这张图还没有你的颜色」+ 三个冷启动入口（自报/测评/传卷）。

**附赠功能**：成长海报——把当前技能树导出为 750×1200 PNG 分享图（纯前端生成）。

**响应式**：容器 `ResizeObserver` 自适应；最小宽度 720px，窄屏容器内横向滚动（有意为之，不做移动端独立视图）。

| ④ 开始 | 学生端 / 教师端双 CTA + GitHub 链接 |

**动效纪律**（现有项目明文的产品决策）：**刻意不劫持滚动**——不做滚动吸附、不分页锁定、不设 sticky 章节轨；章节感只靠最小高与留白；滚动揭示进视口一次性触发；逐字动画的每个字对读屏隐藏、完整句走 aria-label。

## 4. 全局设计约束

> 以下均为现有项目实测值。重构时哪些保留、哪些推翻，见 §6 逐项确认。

### 4.1 色彩

**掌握度状态带**（全站唯一事实源，阈值 0.4 / 0.6 / 0.8，有教育学语义与测试锁定）：

| 档 | 名称 | 色值 | 软底 |
| --- | --- | --- | --- |
| 1 | 待巩固 | `#E8894A` 暖橙 | `#FBEDE2` |
| 2 | 不稳定 | `#D9B23F` 黄 | `#F8F1DC` |
| 3 | 基本掌握 | `#79B8A6` 浅青绿 | `#E7F2EF` |
| 4 | 已掌握 | `#2F9C7C` 青绿 | `#E2F1EC` |

**主色**：低饱和青蓝 `#4E8FB0`（浅底版 `#EAF2F6`；深色主题提亮 `#6FB3D4`、按压 `#3D7E9E`）。**禁用刺眼大红**；错误/警示用陶土橙 `#C96A3A`（双主题通用不变量）。

**语义角色令牌**（双主题各取一套值，组件只引用角色名）：canvas（页面底）/ surface（卡面）/ raised（悬浮面）/ ink（正文）/ ink-soft（次级文字）/ line（描边）/ accent（主色）/ accent-veil（主色浅底）/ accent-ink（主色可读深字 `#2E6B87`）/ on-accent（主色上的字）/ danger。

**主题体系**：**默认深色**。深色为「dusk 深海军蓝」体系：底 `#070C14` → 面 `#111A26` → 悬浮 `#18222F` → 描边 `#26374A`，文字 `#E8EEF4` / `#B8C4D0` / `#7A8798`（仅装饰用 `#5A6675`）。浅色为冷白体系：底 `#F5F8F9`、面纯白。主题存 localStorage，首帧内联裁决防闪，meta theme-color 跟随。**打印强制浅色**（防洇墨）。

### 4.2 字体与排版

- 西文：Geist 可变字体 + 等宽 Geist Mono；中文：系统栈（苹方等）
- **全站数字一律等宽对齐**（tabular-nums）——百分比、掌握度、时间、编号都遵守
- 字号刻度：说明字 11px / 界面小字 13px / 阅读正文 15px / 大标题 38px / 超大 42px（落地页标题另设 clamp 2.5→5rem 响应式档）；文档化使用规范：页面标题 20 / 区块标题 16 / 正文 14 / 信息标签 13 / 徽标图例 12
- 长串标识（ID、邀请码、文件名）强制断行或等宽展示

### 4.3 间距与栅格

- 内容宽度三档（prose 672 / standard 768 / wide 1152），全部居中
- 页边距：桌面 24px，<720px 收到 16px（顶栏与正文同步，保左基线）
- 顶栏高 56px（吸顶）；已知 720px 整数宽处 88px 的既有边界（见 §3.0）

### 4.4 圆角与阴影

- 圆角三档：元素内小块 6px / 控件 10px / 卡面 16px
- 阴影两枚令牌：card（贴面）/ overlay（悬浮层）；深色主题阴影改用 1px 内高光替代投影

### 4.5 断点（单一来源纪律）

| 断点 | 用途 |
| --- | --- |
| **720px**（唯一具名断点 `nav`） | 顶栏收进汉堡抽屉；对话页双栏切单栏；触控目标抬升；任意值断点被项目测试**明文禁止** |
| 1280px | 右侧对话面板由覆盖抽屉转常驻挤压 |
| 768px | 报告页双栏 |
| sm / lg | 教师端卡片墙列数（2/3 列） |

### 4.6 层级（z-index）

三枚刻度：导航 40 / 覆盖层（抽屉、模态、面板）50 / toast 60。

### 4.7 动效

- 时长刻度：rise 320ms / fade 160ms / 抽屉滑入 240ms / 路由转场 280ms / 滚动揭示 420ms——**上限约 420ms，全部零 delay**（快而不躁）
- 三套降级全有落点：`prefers-reduced-motion` 全局压到近零；`prefers-reduced-transparency` 降玻璃底；打印禁全部动画
- 「隐藏是被授予的权限」：滚动揭示默认不隐藏内容，仅在支持动效的环境隐藏

### 4.8 文案纪律

- 学长口吻 + 评判词黑名单（「错误」「很差」「笨」等，有逐字锁定的文案库）
- 按钮 loading 文案自切（「正在批改…」「正在记下…」），不用裸转圈
- 网络错误统一拟人文案「网络开小差了，稍后再试一次」
- 错误提示说「下一步怎么办」（「第 N 题还没标对错」），不 dumps 原始报错

## 5. 可访问性要求

现有项目已达到的实测水准（重构不应低于此）：

**键盘导航**

- 全站 `:focus-visible` 统一焦点环（2px 主色描边 + 2px 偏移）
- 抽屉/模态焦点陷阱（Tab 循环不逃出）、Esc 关闭、关闭后焦点归还触发器
- 打开覆盖层时正文 `aria-hidden`；装饰性动效对读屏隐藏、语义走 aria-label

**语义与读屏**

- 模态 `role=dialog + aria-modal`；toast `aria-live=polite`；骨架屏 `role=status`
- 按钮型组件 aria-label 必填（组件级强制）；开合类控件一律 aria-pressed / aria-expanded + aria-controls
- 表单字段自动注入 aria-invalid / aria-describedby 关联

**对比度（全部实测过）**

- 正文与次级文字浅色主题 ≥ 5.17:1；主色可读字 5.95:1；导航激活态 11.97:1；错误色双主题 5.27:1
- 已知遗留：ModelBadge 徽标 3.15:1（与顶栏激活 tab 同款既有配对，项目明文声明不修）——重构时应解决

**触控与移动**

- 触控目标：窄屏按钮 ≥36px、主按钮 44px、图标钮 36/44px 两档
- 安全区：刘海屏 `env(safe-area-inset)` 适配（桌面恒为零）
- 外壳 `min-h-dvh` 防移动端地址栏跳动

**降级**：reduced-motion / reduced-transparency / print 三套环境均有完整降级路径（见 §4.7）。

**图谱无障碍**：画布旁提供文字版知识点清单（折叠 details 兜底）。
